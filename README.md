## Cómo clonar y ejecutar el proyecto

1. Clonar el repositorio:
   git clone https://github.com/ArturoZamoranoB/Proyecto-Web-Ejemplo.git

2. Abrir el archivo index.html en el navegador o usar la extensión Live Server en Visual Studio Code.

## Ramas del proyecto

- main: rama principal con la versión estable del proyecto.
- feature-mejora-estilo: rama utilizada para mejorar el estilo y la presentación visual del sitio web.
